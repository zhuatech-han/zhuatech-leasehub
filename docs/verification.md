## 备份与恢复

从独立 TEST 数据库生成私有 SQL 备份，恢复到另一全新空数据库。23 张业务表、132 行数据，逐表排序后摘要及行数完全相同。Flyway V1 校验通过，恢复后的健康、登录、合同冻结信息、历史记录、结算和数据隔离复核通过。SQL 备份、口令与私有测试状态不在仓库内。

此为一次小规模 TEST 恢复演练，不代表灾备服务等级、生产恢复时长或客户历史数据迁移已验收。

## 页面验收

Edge 实际操作覆盖总部、合作商、客户三个工作台：登录、经营总览、设备新建、角色权限、报表、平台设置、合同冻结计价与分期预览、客户本人账单，以及设备交付与归还操作。独立检查设备归还链路：合作商登记归还后保持占用，客户确认后合同为已归还、设备恢复合作商可用；11 个后续 HTTP 断言通过，原账单与已收款未被清除。

1280×800 桌面页面与390×844客户页面断点检查完成。手机表格在自身容器内横向滚动，未产生页面横向溢出；本项目以业务工作台为主，未提供原生小程序。真实截图见 [README](../README.md)，全部为 TEST 数据，没有使用原型图冒充功能。
