# LeaseHub 业务范围

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 微信 zhuatech / zhuatech2。

## 经营模型

一个总部持有设备并投放给多个合作商，合作商向自己的终端客户出租。总部负责设备投放、费率发布、核销和结算审核；合作商负责接收、合同、交付、收款登记与成本申报；客户只能确认自己的合同、查询自己的账单和核销结果。账户由总部邀请式创建，无匿名注册。

## 生命周期与边界

- 设备：总部可用 → 投放中 → 合作商可用 → 待客户确认占用 → 待设备交付/客户接收 → 在租 → 双方确认归还 → 合作商可用。可用设备才可维保或回收，回收必须总部确认；总部可用设备才可处置。按版本提交动作，重复或过期动作拒绝。
- 合同：草稿 → 待客户确认 → 生效 → 归还完成；草稿/待确认可取消。提交占用设备，客户本人确认时生成冻结计价账单；合作商登记实际交付、客户确认接收后设备在租，归还同样需双方确认。归还不免除已生成应收，不自动计算违约金、押金、提前终止退款或保险赔款。
- 计价：日租金，按合同开始日逐月划分结算账期，各段实际天数乘日租金；开始日含、结束日不含。到期日为段末日，不把日租金称为月租。合同最长 366 天，人民币整数分，无多币种、融资利息或税务发票。
- 收款：按单账单登记线下金额、实际收款日期和凭据号，总部核销时复核未收金额。凭据号在合作商内唯一；核销记录可附理由冲正，但已被结算锁定的记录须先撤销结算。没有银行资金自动验证。
- 成本：合作商提交设备维保/运输等费用，总部批准后才计入结算。归属月份固定，明细一旦被结算占用不可再改动。
- 分成：按核销实际收款月份归集，每笔总部分成向下取整到分，合作商保留余数；批准成本由总部承担，从总部应收分成扣除。总部净额为负时，记为总部应付合作商。收款与成本明细只能存在于一个未取消/未冲正结算中。
- 结算：制单 → 独立总部审核 → 手工登记转款；审核人与制单人不同。转款有凭据与方向，不能据此宣称银行到账；撤销转款追加冲正记录，之后才可冲正结算并释放明细。历史计算和流水保留。
- 风险：根据未收账单和到期日显示逾期，显示空闲设备；运营可建立有负责人、跟进记录和下次跟进日期的风险工单。站内清单，不发送邮件/短信。

## 首版验收范围

账号/角色权限、总部与合作商隔离、客户对象权限、设备占用与交接、冻结计价、分段账单、部分核销及超额拦截、成本审核、结算明细占用/双人复核/负净额/冲正、查询分页与过滤、经营统计和安全 CSV 导出、字典/设置/菜单、审计、持久化与迁移。

## 部署定位

单总部、单应用实例、低容量部署。写事务通过数据库协调锁串行，确保跨实例写入顺序，但会话在应用内存，暂不支持横向扩容。银行、电子签章、财务系统、遥测、信创数据库、历史数据迁移、高并发和真实客户上线需另行联调与验收。
