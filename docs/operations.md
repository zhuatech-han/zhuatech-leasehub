# LeaseHub 操作手册

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 微信 zhuatech / zhuatech2。

## 总部准备

1. 登录初始管理员，建立合作商组织；在客户资料选择合作商创建真实客户资料。
2. 系统管理创建合作商经理、总部财务和客户账号。客户账号绑定已建客户，密码12–128位含大小写字母与数字。不要将账号或密码截图公开。
3. 自定义角色只能在原范围内配置岗位权限；`approve`是总部审核，`admin`是总部系统管理，客户仅`portal`。账号机构和客户关系不能更换，人员跨机构时创建新账号保留原记录。
4. 设备与投放登记设备名称、唯一序列号、分类和投入成本。按区域发布不可覆盖的日租金费率版本及总部份额。

## 合作商接收与租赁

1. 总部投放设备，合作商登录确认实际收到。此时设备在合作商范围可用。
2. 创建合同，选择自己的客户、可用设备、有效费率版本，填写开始和结束日期。结束日不计租金，最长366天。先查客户账号是否启用，再提交。
3. 提交后设备占用。客户登录“我的租赁”，打开详情核对冻结名称、设备序列号、日租金、总金额和分期预览，确认合同后生成账单。页面确认不提供电子签章证明。
4. 合作商登记实际交付日期、交接说明；客户确认实际接收后设备在租。未接收前不能登记归还或再次出租。
5. 合作商实际收到归还设备后登记日期、情况；客户核对后确认归还，设备释放。发现登记错误可先撤销待确认归还。归还不自动减免既有账单或计算损坏赔偿，账务调整需明确业务规则后另行开发。

## 核销与结算

1. 合作商按账单登记已收的线下租金、日期、凭据号和说明。待审核不算收款；总部财务核对凭据、余额后核销，支持部分收款，不能超额核销。
2. 合作商申报总部承担的真实运营成本，总部审核。未批准成本不入结算，分类可由总部维护。
3. 按收款/费用实际月份生成结算：每笔收款按合同冻结总部分成比例算到分，总部承担批准成本。正净额合作商转总部，负净额总部转合作商。
4. 制单人与审核人必须不同。打开结算详情核对全部来源明细。明细只允许进入一个有效结算。
5. 银行转款在系统外完成并核实后，登记真实日期和凭据。系统不会发起资金转移。登记错的转款先追加撤销登记，再冲正结算；之后才可冲正原收款/成本。
6. 补录同月资金或成本时，已有效结算须先按流程撤销/冲正再重新制单；已登记转款须先处理真实资金及台账差异，不把台账冲正当成银行退款。

## 风险与统计

经营总览计算实际逾期、设备状态、已审核结算和到期跟进。风险工单设置有风险权限的负责人，追加记录与下次跟进日期。闲置按最近设备状态日期及平台设置阈值计算；没有AI信用评分、短信、邮件或设备遥测证明。

查询按名称、序列号、凭据或编号及状态过滤，列表每页20条。关联下拉每类最多1000条，CSV按当前账号范围导出最多10000条全部记录；不沿用列表的关键词过滤。超过该规模需扩展远程检索与分批导出。

## 配置与日常维护

系统管理维护业务字典、闲置预警天数、平台名称及菜单显示顺序。禁用账号/机构立即影响下一次请求。费率变动新增版本，勿改变旧合同快照。审计和历史只读，不在数据库手工修改财务状态或迁移历史。
